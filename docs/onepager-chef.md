## Rollenübersicht
1. Supervisor
Gesamtverantwortung: Organisationsstruktur (Company → Bereich → Abteilung → Team → Subteam), Grundeinstellungen (Firmenname, Logo, Farbe, Tätigkeiten), Feiertage, Supervisoren und Teamleiter anlegen.
2. Teamleiter
Verantwortung für das eigene Team: Teammitglieder anlegen/bearbeiten, Team-Kernarbeitszeit festlegen, Teamkalender prüfen.
3. Benutzer
Eigene Arbeitszeit pflegen (Templates, Tagesbearbeitung), Status wählen (z. B. Support, Urlaub, Krank), Profil verwalten, Schichttausch anfragen.
